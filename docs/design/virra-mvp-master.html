The VIRRA moats

Fuelling language: No calorie restriction, no diet culture. Cycle-synced macro targets with "fuelling" framing throughout.

02 System Architecture 3-layer: mobile · backend · external
Mobile app · Expo + expo-router
Cycle Phase Engine
On-device, offline. Period date + cycle length + today → phase (menstrual / follicular / ovulatory / luteal). Pure deterministic math. No network round trip. Feeds all features.
Training & Activity Framework
MVP: Structured running plans (5K → marathon), cycle-adjusted weekly load, GPS run tracking.
Framework: Generic activity log — type field accepts run / swim / strength / yoga / other. Multi-sport plans added post-MVP without schema changes.
Design System
Vol. 02 tokens: Big Shoulders Display, Fraunces, Inter, Space Mono. Pulse (#D4FF26), Heat (#FF2E7E), Mile (#0A0A0F), Breath (#F4EDE0), Dawn (#FF6B3D).
State · Zustand
Local state for cycle phase, today's session, nutrition log. Synced to Supabase. Core features work offline.
Backend · Supabase
Auth + Database
Postgres. Row-level security per user. Email + Apple Sign-In. All user data scoped by RLS policy.
Training Store
Plan templates (sport_type extensible). User active plan instance. Planned sessions with cycle-phase load overrides. Activities table (generic type field). run_details child table for GPS/HR/splits.
RevenueCat
Entitlement management. Validates App Store receipts. Webhook → Supabase subscriptions table. Trial-end reminders triggered via webhook at day 11 + day 13.
Push · Expo + APNs
State-aware. Notifications cancelled when their trigger action is completed. Never fires if action already done.
Storage
Article images, user avatars. CDN-backed Supabase Storage.
External services
Apple HealthKit
Primary activity source. HKObserverQuery with background delivery. HKAnchoredObjectQuery for incremental imports. Reads: workouts, HR, steps, weight. Writes: completed workouts back to Health app. Auto-imports Apple Watch + Garmin/Wahoo via HealthKit bridge.
Nutritionix API
Food database + barcode scanning. Natural language search. Free tier sufficient for MVP volume.
Claude Haiku
Weekly/monthly narrative insights. Synthesises cycle phase + nutrition + training signals into non-repetitive, personalised copy. Response cached — not regenerated every session.
Astro site (existing)
virra.app — marketing + blog. Completely independent. No shared code.

Workouts sync to HealthKit on completion. HKObserverQuery fires in background — app imports silently. GPS trace, HR, pace, splits, calories. Zero user action required.
Background · silent

09 Phase 2 Post-launch — build when you have users and revenue
Multi-sport Structured Plans
Swim, strength, cycling plans. Schema already supports it — sport_type field on plan_templates. Just needs plan content + UI.
Community & Social
Group challenges, community feed, follow other runners. Build when you have enough users to feel alive.
Route Planning
Discover and save running routes. Low differentiation vs Strava — deprioritise until core is strong.
Coach-to-Client Portal
Assign custom plans to individual clients. Trainerize replacement. Build once consumer side is validated.
Perimenopause Track
Dedicated track with adapted training + nutrition. Massive underserved market. Needs its own content investment.
Strava Integration
Two-way sync. VIRRA becomes the brain, Strava the social layer. Reduces acquisition friction.
Race Day Planning
Pre-race fuelling plan, taper guidance, cycle-phase-aware race day strategy.
Android
React Native already supports it. Launch 2-3 months post iOS once product is stable.
Wearable Expansion
Direct Garmin Connect IQ + Wahoo API integration beyond the HealthKit bridge.
