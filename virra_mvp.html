VIRRA
MVP Feature Strategy — v1.0

The one-line MVP brief

A subscription app that replaces Runna + MyFitnessPal + a cycle tracker for women runners — with female health woven through every feature, not bolted on.

Must-have Ship without these and VIRRA isn't viable
Cycle phase tracking & integration
User logs period start date. App maps her to a cycle phase (menstrual, follicular, ovulatory, luteal) and uses this to inform training load, nutrition guidance, and recovery cues throughout the app.
★ This is the VIRRA moat. Without it, you're just another Runna clone. Every competitor ignores this.
VIRRA-onlyCore value prop
Adaptive training plans
Structured running plans (5K through marathon) that adjust based on cycle phase, not just pace/fitness. Plans built by you — delivered by the platform. Users select a goal and get a dynamic week-by-week plan.
This is the primary reason someone pays a subscription. It replaces Runna.
CoreSubscription driver
Run logging & GPS tracking
In-app run tracking with GPS, pace, distance, heart rate (via phone/watch). Post-run manual logging option. Replaces Strava for basic run capture.
Table stakes for any running app. Users won't leave Strava unless you capture this.
Table stakes
Nutrition tracking (female-first)
Food logging with macro tracking. Crucially: targets shift with cycle phase (e.g. higher carbs in luteal phase). No calorie-restriction framing — fuelling language only. Replaces MyFitnessPal without the diet culture.
★ Second VIRRA moat. MFP is diet-culture hell. Cycle-synced nutrition targets exist nowhere else.
VIRRA-onlyRetention driver
Daily dashboard
Home screen showing: today's training, current cycle phase, top fuelling cue for the day, last run summary, weekly progress ring. The "one screen to rule them all" that replaces app-switching.
The dashboard IS the product promise — everything in one place, built for her.
Core UX
Female health education library
Short-form articles and explainers: cycle phases & performance, fuelling for women, perimenopause & running, RED-S, iron deficiency, hormones & training. Written by you. Searchable. Linked contextually from training and nutrition features.
Builds trust, reduces churn, differentiates from every competitor. Your PT quals make this credible.

Subscription & payments
Monthly and annual tiers via RevenueCat (handles App Store + Play Store). Simple paywall — free trial (7 or 14 days), then paid. No free tier at launch.
No subscription = no business. Must ship day one.

User profile & onboarding flow
Onboarding capturing: fitness level, running goal, cycle data (period date, avg length), dietary preferences. Personalises plans and nutrition targets from day one.
Personalisation makes the product feel built for her. Critical for day-1 retention.

Wearable sync (Garmin / Apple Watch / Wahoo)
Pull run data automatically from connected devices. Users should not have to log manually if they run with a watch.
Without this, tech-savvy runners feel the friction immediately. High retention impact.
API integration
Progress & insights view
Monthly view of: miles run, training plan adherence, nutrition consistency, cycle phase correlation with performance. Helps users see the VIRRA effect over time.
Users who see progress data churn at much lower rates.
Retention
Push notifications & training reminders
Smart reminders for: today's run, cycle phase shifts, fuelling reminders on long run days. Personalised, not spammy.
Drives daily active use — critical for subscription retention metrics.

Food database & barcode scanning
Integrated food database with barcode scanning. Use an existing API (Nutritionix or Open Food Facts) — don't build from scratch.
Nutrition logging without a food database is unusable. Non-negotiable for that feature to work.

Symptom & wellbeing logging
Quick daily check-in: energy, mood, sleep, symptoms. Feeds back into training load suggestions. Makes the cycle-performance connection tangible and personal.
High perceived value, relatively low build complexity.
